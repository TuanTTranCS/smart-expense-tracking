# Main Screen Extraction Retry

Last updated: 2026-10-01

Status: ✅ Done — verified on a physical Pixel 7, confirmed by Hugo on 2026-10-01.

## Behavior

Main provides **Retry extraction** after the selected image loads, including after a failed extraction. Retry sends the retained, processed image with the provider currently selected on Main, as requested by Hugo. It does not reopen the picker or reload/reduce the image. The provider is snapshotted when retry starts; subsequent selection changes do not affect that request.

Retry retains the image preview and replaces the current review results, edits, and transient debug/export previews. Existing persisted export records remain intact. Extraction retry does not upload or retry an export. The control explains review replacement and is disabled during extraction, export, or provider configuration work. A failed image load requires choosing the image again.
