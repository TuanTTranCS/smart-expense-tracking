# Main and Settings adaptive UI

Date: 2026-10-12

## Scope

Apply the requested financial UI hierarchy to the existing Main and Settings destinations. Hugo selected **Android dynamic colors and semantic tokens only** over a fixed emerald/mint palette. Android 12+ uses wallpaper-derived Material 3 schemes; earlier versions use Material 3 light/dark defaults. System appearance changes select the matching scheme. No theme preference, account tier, expense history model, or receipt line-item data model is introduced.

## Implementation

- Shared `SmartExpenseTheme` supplies system appearance, semantic color roles and bundled Inter typography. Headings and financial totals use bold weight and −0.02em tracking; receipt dates and numeric fields use bundled Roboto Mono. Fonts and OFL licenses ship locally for offline rendering.
- Main separates provider configuration, input actions and review/export into padded sections. Receipt/review cards use 16dp corners and matched `surfaceVariant`/`onSurfaceVariant` roles. Status badges pair primary, secondary and error containers with their corresponding foreground roles. Actions wrap at narrow widths.
- Image-viewer controls sit in their own opaque themed toolbar above the remaining fitted-image viewport, preserving complete-image review, zoom and pan.
- Settings groups models, batch processing, preprocessing, Debug and device name into cards with dividers and uniform 24dp icons. Settings toggles and choices have full-row interactions and explicit 48dp minimum height. Profile actions and concurrency choices wrap; existing checkbox/switch semantics remain intact.
- ViewModels, state objects, navigation, input launchers, extraction/retry/export callbacks, consent gates, immutable exports and unsaved-profile protection remain unchanged.

## Requirements checked

- `REQ-UI-001..006`, `AC-022..025`: destination boundaries, provider/OneDrive semantics, state preservation, protected Back and Debug controls.
- `REQ-UI-007..008`, `AC-032..033`: complete processed-image preview and bounded zoom controls.
- `REQ-UI-009..014`, `AC-034..039`: retained provider controls, retry, safe drawing insets, profile actions and copyable diagnostics.
- Existing extraction/export regression tests retain the requirements for validation, busy guards and confirmation. This presentation update does not change inference or handoff contracts.
