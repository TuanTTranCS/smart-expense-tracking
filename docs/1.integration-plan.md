# Phase 1 Integration Plan

Last updated: 2026-09-05

## Purpose

Phase 1 turns the known integration risks from `docs/PLAN.md`, `docs/requirements.md`, and `docs/gap-closing-plan-details.md` into small, verifiable spikes. The goal is not to build the MVP yet. The goal is to prove the main Android, OneDrive, Hermes, PowerShell, and Excel integration paths before committing to the Phase 2 and Phase 3 implementations.

## Phase 1 Outcomes

Phase 1 is complete when the project has:

- A confirmed Android extraction strategy using a provider abstraction, with local Google AI Edge APIs or LiteRT-LM as the default provider and optional OpenAI-compatible API providers configured through Settings.
- A defined Settings Model Selector contract for provider and model selection.
- A working Microsoft Graph upload spike that writes a normalized receipt JPEG first and then publishes its complete Version 2 JSON handoff.
- A confirmed Hermes-to-PowerShell execution contract.
- A workbook update spike that inserts one expense row after row 12 in a copy of `Canada plan.xlsx`.
- A deterministic duplicate/similar-record detection rule tested against the monthly worksheet layout.
- Updated project docs showing the chosen integration decisions, remaining risks, and any implementation constraints discovered by the spikes.

## Non-Goals

- Do not build the full Android MVP UI in Phase 1.
- Do not automate the real production workbook directly; use a copy for all workbook spikes.
- Do not upload the original/full-resolution receipt to OneDrive; upload only the required normalized JPEG below 200 KB.
- Do not depend on Amazon Photos links for MVP expense processing.
- Do not mark a spike done until the behavior is demonstrated, covered by focused tests where code exists, and checked against `docs/requirements.md`.

## Workstream Order

Run the workstreams in this order because later spikes depend on earlier contracts:

1. Define fixture data and handoff schema contract.
2. Spike OpenAI-compatible API extraction and provider selection.
3. Spike Microsoft Graph upload to OneDrive.
4. Spike Hermes PowerShell execution.
5. Spike workbook row insertion and mapping.
6. Spike duplicate and similar-record detection.
7. Spike Android local extraction on device.
8. Consolidate decisions and update Phase 2/3 plans.
